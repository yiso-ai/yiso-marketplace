# 验收、迁移与恢复

## 先证据后切换

1. 明确旧系统只读窗口和唯一新writer；备份前获取完整真实状态/全部分页，含未决项、来源身份、旧引用、权限、代码与schema版本。哈希和计数从实际字节计算，不从文件名或旧报告猜。
2. 在隔离目标导入，保留稳定ID、原文UTF-8、机构日期、来源/去重/覆盖、旧URL、原始归属和全部恢复义务；不要把草稿/备料算已归档。迁移不是授权重扫邮箱、恢复暂停或补历史。
3. 核整个数据集，不能只对总条数：逐表字段计数/规范哈希、逐正文hash、FK/integrity、当前body证据offset与quote、别名/层级/端点、原生表格与来源、按 images.md 核原图/预览字节哈希及图片关联、FTS投影完整性、旧引用可定位。
4. 核主归属唯一、无primary/related重叠、显式无效不回退、关联不复制正文；查询排序、覆盖分子分母与目录计数一致，未审不混作已审。
5. 并发、重复批次、旧epoch/config、CAS冲突、崩溃中断、未知响应及恢复重试都测；同一batch checksum重复应幂等，不同checksum拒绝。结果未知先查原run/receipt/head，不换ID盲重放。
6. 扫描进度与归档完成边界分开；完整扫描可前移，但持久携带逐项未决，不让完成游标越过适用缺口。迟到/移动资料再核真实身份和内容；仅相关namespace受阻，不将无关历史未知强行归为当前来源。全局账户不符/分页不完整/恢复基础缺失则停止整轮。
7. 运行身份、来源范围、写入协议和恢复路径独立验收后才授权切换。旧writer停止、旧系统只读保留，不双写、不删除、不自动回退。源包存在或测试READY不等于用户允许扫描。

## 前端与权限验收

- 所有页面/API匿名、非授权身份及授权本人实际测试，权限保持预期；源码push/部署不是认证测试。
- 正文、日期、标题、机构、内部原作者/机构保留及后台私人字段隔离、段落/bullet/table、四栏、年份/档案筛选、完整分页、双向关联与深链逐项核验。
- 桌面/手机视觉、键盘、折叠重复点击、筛选清除、Back/Forward、加载中切换和失败恢复。若浏览器不可用，说明仅源码/单元测试，不能写“视觉通过”。
- 检查bundle、API、日志、数据库导出与临时文件不意外暴露私人locator/密钥；分享技能包只含通用代码与合成数据。

## 备份与恢复

完整备份包括canonical数据、证据、来源/覆盖/处理账本、行业主题与历史映射、运行head/cursor/gap、schema migrations/triggers/views/indexes、代码release与配置结构，以及应保留图片的归档副本、原图/预览清单与全部关联。数据库和图片必须联合备份并实际隔离恢复；只有 SQLite 或仍依赖原材料路径不能称完整恢复。密钥从批准秘密管理恢复，不进入技能或普通ZIP。验证导出行数/哈希/完整分页并在隔离实例实际恢复；只有文件上传成功不叫恢复验证通过。

源码备份不是数据库备份；平台托管数据库不是承诺用户Cloudflare控制台可见。导出/保留/分享/定时备份均按本人授权处理，不自动创建日程。备份失败保留前一次成功备份，完成提醒不等于自动备份授权。

## 本地恢复一致性工具

`python scripts/verify_sqlite_snapshot.py source.sqlite restored.sqlite` 只读比较两个已获授权的本地快照，核integrity/FK、schema（含trigger/view/index）及逐表完整行哈希，输出不同表名而不输出研究正文。退出0只代表这两个快照等价，不证明来源授权、云端导出完整、业务语义或生产恢复成功。旧数据需要映射时先核明确变换规则，不能要求哈希相等后忽略差异。
