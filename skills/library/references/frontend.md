# 前端阅读契约

## 目录与阅读

- 浅色暖白阅读界面；桌面左侧目录/筛选，右侧主阅读区；手机堆叠并避免表格撑宽。
- 首页公司/主题切换，名称、别名、代码检索；公司入口仅含实际有效档案，分类节点可导航但不虚报材料数。
- 档案顶部返回目录；栏顺序固定内部分析 → 卖方研究 → 新闻 → 关联研究。连续全文，支持栏/条目折叠、年份定位、回到顶部及当前档案搜索。
- 既有条目原标题独立一行，新卖方条目用已核实中文实质标题，下一行材料日期和适用机构：`YYYY-MM-DD | 机构`。内部日期、标题、已批准原作者/机构均保留；按明确display_author呈现，不因分类静默删署名，也不将后台私人作者字段自动公开。材料日期倒序，同日用不可变键稳定排序。
- 原有段落、分层bullet、正文标题和非图片原生表格保留；不要为“无杂项”压缩成几句摘要。未知日期不造日期；后台待核与前端清晰分离。
- 关联研究保留原主归属引用/跳转和简短理由，不再复制完整正文；公司↔主题从同一已核证据生成双向导航。
- 行业路径展示到公司实际归入的节点，区分官方分类与研究映射。一级或二级归类可直接出现在该层，既有三级路径仍可浏览。主题层级、跨主题关联及覆盖数/比例独立显示。不能把行业成分关系自动作为主题研究证据。

## 查询、URL与状态

分页必须直到总数一致，校验重复ID、偏移单调、稳定排序；大档案避免只取首50条就称全文。API、目录计数、主研究/关联数与数据库同一head一致。当前档案过滤与全库搜索明确区分，不能把只筛已加载结果标为全库搜索。搜索全已加载档案前确保全部分页完成。

支持目录/档案/段落深链、浏览器Back/Forward，切换档案取消旧请求，旧响应不得覆盖新档案。折叠或清空过滤后保持当前选中状态；空结果和加载失败不同，失败不显示“没有研究”。仅数据提交及读回成功才显示最近成功更新时间。

## 安全

正文使用安全文字渲染，若支持Markdown则严格白名单，不解释原HTML或任意URL；不执行脚本、不自动加载任意外部资源。仅通过已验证的受权限保护资产接口展示获准归档图片，检查资产 ID、MIME 与访问权限，不暴露本机路径或直接信任原文 URL；详见 [images.md](images.md)。保留原始证据和图片关联，不能用显示清理静默删掉应保留图片或损坏内部原文。无法分离的来源杂项隔离，避免篡改原文。

reader API采用显式字段白名单；无private_locator、邮箱来源URL、原文件路径、后台私人作者字段、凭证、锁token、运行调试信息或未审字段。不要仅在CSS隐藏。私人原文只发给获授权用户；默认不提供公开bundle内嵌研究。

Sites参考实例依赖平台访问边界；复制源代码到别的主机不会继承认证。新Sites按当前官方身份/权限机制核验，自管另实现身份及服务端授权。不要写“route自带独立认证”这种未经验证保证。
