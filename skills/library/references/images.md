# 图片筛选、资产与恢复

现行归档包含符合以下规则的图片，旧的一律不归档或删除图片规则已取代。适用于已授权新归档和未来重新归档；旧档不回补，不因本规则自动删除原件、修改既有记录或恢复暂停来源。

## 筛选与内容
- 多张截图构成的长文/报告按一份报告提炼关键文字，不保留报告截图；长报告内部图表不保存，可提炼明确可读且有用的数据并保留来源，不猜测数字。
- 独立且有实质增量的关键图表、独立图片表格保存原图副本。若正文已覆盖实际使用的关键数据和结论，剩余信息不影响判断，可省略并记录理由；不能仅因数据点多就全部保留。
- 不把图片转录冒充内部原文或非图片原生表格；内部相关文字仍按原文完整保留，不能因段落带图就删除文字。

## 存储与关联
- 本地提交时，直接从已审来源文件核验选中的图片。Word 内嵌图须能从指定文档及图像关系定位到原图字节。原图归入 `Library/images/objects/`，已审的必要预览归入 `Library/images/derived/`。如果源文件本身就是选中的独立图片，归档保存这一份图片资产。数据库保存稳定资产 ID、SHA256、相对路径、MIME、大小、尺寸及 Memo/正文/来源关联。
- 保留原图；需要预览时另存派生预览和原图对应关系、转换及审核记录，不用预览冒充原件。关联适当公司、主题及主要指标，维持审核状态和出处，不把待核图解升格为事实。
- 数据库与图片联合备份、迁移和隔离恢复；核对文件存在、字节哈希、双向关联、权限与实际显示，确认不依赖原始材料后才能称自足。原件暂不删除；删除仍需单独授权及适用确认。

## 实现边界
技能说明更新不是生产代码更新。附带文本目录适配器、旧批次校验器和最小前端未实现完整图片保存/关联/显示/联合恢复；不得绕过其校验或丢图凑成功。先检查当前实例已验收的图片能力；缺能力时记录明确阻碍并保留原件，独立实现与测试后再切换，不改现有生产发布包。迁移到另一服务同样需要实际验证上传、私有读取、关联及恢复，文件打包成功不等于图片已可用。
