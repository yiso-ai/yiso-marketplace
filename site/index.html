安装

选择你使用的 Agent。Claude Code 使用原生插件；Cursor 和 Codex 使用同一份开放 Skill。

  1. 01添加插件市场

    claude plugin marketplace add yiso-ai/yiso-marketplace

  2. 02安装此插件

    claude plugin install yisolib@yiso-marketplace

已添加此市场？直接运行第二条命令即可。

安装后执行 /reload-plugins，或重新启动会话。

Cursor 直接加载 SKILL.md。装到用户目录后，在 Agent 对话输入 /library。

  1. 01安装 Skill

    tmp="$(mktemp -d)" curl -fsSL https://github.com/yiso-ai/yiso-marketplace/archive/refs/heads/main.tar.gz | tar -xz -C "$tmp" --strip-components=1 mkdir -p ~/.cursor/skills cp -R "$tmp/plugins/yisolib/skills/library" ~/.cursor/skills/

  2. 02在 Cursor 中调用

    /library 试读我指定的资料目录，先给我看拟归档清单，不要写库。

可在 Customize → Skills 中确认 library 已加载。

Codex 使用开放 Skill 目录。推荐让内置 $skill-installer 从本仓库安装。

  1. 01让 Codex 安装

    $skill-installer 从 https://github.com/yiso-ai/yiso-marketplace/tree/main/plugins/yisolib/skills/library 安装 library

  2. 02在 Codex 中调用

    $library 试读我指定的资料目录，先给我看拟归档清单，不要写库。
手动安装到 ~/.codex/skills
tmp="$(mktemp -d)" curl -fsSL https://github.com/yiso-ai/yiso-marketplace/archive/refs/heads/main.tar.gz | tar -xz -C "$tmp" --strip-components=1 mkdir -p ~/.codex/skills cp -R "$tmp/plugins/yisolib/skills/library" ~/.codex/skills/

使用说明

安装后，把本地资料路径交给 library。它先读取和审阅，明确说“归档”后才写入。

调用方式

调用 /yisolib:library，说明文件位置和本轮任务：

试读
/yisolib:library 只试读这个目录，先列出会收录的 Memo、主归属和证据，不写数据库。
授权归档
/yisolib:library 归档这批资料；新公司按主营业务归入申万 2021 二级，无法区分二级时归入一级。
Word 增量
/yisolib:library 比对这份更新的 Word，只归档已核实的新增和修订；有候选旧稿时先让我确认。

环境要求

  • Claude Code（插件），或 Cursor / Codex（Skill）。
  • Python 3.10+，本地演示和随包脚本使用 Python 标准库。
  • 正式归档需要一个已配置的 Library 目标；本地模板可先用合成数据验证。
  • 插件本身不包含 API Key、邮箱账号或数据库导出。

本地合成演示

在插件源码的 plugins/yisolib/skills/library 目录下运行，不会读取真实研究：

python assets/starter/starter.py init --db /tmp/library-demo.sqlite python assets/starter/starter.py import --db /tmp/library-demo.sqlite --input assets/starter/fixture.json python assets/starter/starter.py serve --db /tmp/library-demo.sqlite --port 8765

打开 http://127.0.0.1:8765。模板只绑定本机地址，使用合成数据。

安全边界

  • 只读取本次任务明确给出的文件或文件夹，不自动扩大范围。
  • “试读”“预览”“查重”不会写入数据库；明确“归档”后才进入写入和回执。
  • 关键图片可以保存，但不把 OCR 结果冒充原生文字。
  • 数据库、出处记录和图片默认留在本地或你配置的私有环境。

配置项

这个插件没有内置 API Key 或必填服务配置。目标 Library 路径、资料来源和写入范围由你的本地环境与本轮任务确定。

兼容性说明

本仓库以 Claude Code 插件标准组织：市场清单位于 .claude-plugin/marketplace.json，插件清单位于 plugins/yisolib/.claude-plugin/plugin.json，技能入口位于 plugins/yisolib/skills/library/SKILL.md。Claude Code 可直接使用插件命令；Cursor 与 Codex 将同一份 Skill 复制到各自用户目录加载。其他 Agent 安装时仍需按自身标准转换目录、清单、组件发现规则和调用命令。

常见问题

如何确认安装成功？

Claude Code 输入 /yisolib:library；Cursor 输入 /library；Codex 输入 $library。能进入读取和审阅流程即表示加载成功。

会自动读取我的邮箱吗？

不会。Library 只处理你给出的本地路径。邮箱或云端来源需要由你的原生连接器单独读取，再作为明确输入交给 Library。

没有 claude plugin 命令时怎么安装？

可以下载仓库，只复制其中的 plugins/yisolib/skills/library。此方式下直接调用 /library。

tmp="$(mktemp -d)" curl -fsSL https://github.com/yiso-ai/yiso-marketplace/archive/refs/heads/main.tar.gz | tar -xz -C "$tmp" --strip-components=1 mkdir -p ~/.claude/skills cp -R "$tmp/plugins/yisolib/skills/library" ~/.claude/skills/
如何更新和卸载？
claude plugin marketplace update claude plugin update yisolib
claude plugin uninstall yisolib
